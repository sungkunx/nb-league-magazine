글을 내거나 운영 방식이 바뀌면 이 문서의 "현재 상태"와 해당 항목을 같이 고친다.

## 한 주의 흐름 (운영자가 정함)

| 글 | `kind` | 언제 (한국 시간) | 기준 데이터 |
|---|---|---|---|
| 결과 | `week-end` | 월요일 오후 수집 뒤 (11/1까지 16:05, 11/2부터 17:05 시작, 보통 5~10분 걸림) | 팩트시트 "주간 확정" |
| 만평 문안 | (글 아님, 대화로 전달) | 결과와 같이 | 같은 팩트시트 |
| 이주의 예측 | `week-start` | 결과 다음 (같은 날 밤이 보통) | 새 주 로스터 + NBA 일정 |
| D-2 점검 | `week-mid` | 주가 끝나기 이틀 전 = 토요일 오후 수집 뒤 (미국 금요일 경기까지 반영) | 팩트시트 + 남은 이틀 일정 |
| 만평 글 | `week-cartoon` | 운영자가 그림 3장을 보내면 | — |

- 첫 화면 칸 이름: 이주의 예측 / 결과 / 만평. D-2 점검·특집·웨이버·호외는 그 주 "이번 주 기사" 목록에 들어간다.
- 모든 글은 `status: review`로 올리고 미리보기 주소를 알린 뒤, 운영자가 "발행"이라고 하면 `python -m nbl publish <파일 이름>`.
- 오후 수집이 끝났는지는 `git pull` 후 `git log`에 `data: <그 날짜>` 커밋이 있는지로 본다. 기다릴 때는 이 확인을 반복한다. (`origin/main` 참조는 이 작업 공간에 없어서 쓰지 않는다.)

## 글별 구성 (본보기 글을 먼저 읽는다)

- **이주의 예측** — 본보기 `w01-start.md`, `w02-start.md`

  2. 매치업 8개: `### N. 팀 (순위, 전적) vs 팀 (순위, 전적)` → 이번 주 경기 수(괄호에 결장 표시 뺀 수) → 두 팀 강점·약점(지난주 카테고리 리그 순위) → 관전 포인트 → `예상: 팀 **6-4** ⭐⭐`

- **D-2 점검** — 본보기 `w01-mid.md`
  현재 스코어(`{{matchups}}`) → 예상 채점 표(순항/동점/역주행/접전) → 남은 이틀 경기 수 표 → 매치업별 하프타임 분석(뒤집힐 카테고리와 차이) → 트랜잭션(짧게 머문 영입 등) → MVP·LVP 중간 표 → 아웃트로

  최종 스코어(`{{matchups}}`)·순위(`{{standings}}`) → 예상 최종 채점 → 매치업별 결과 → MVP·LVP 표 → 주말 트랜잭션 → 아웃트로(다음 주 대진 한 줄)

- **이번 주 NBA 일정**: Claude in Chrome 탭에서 `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard?dates=YYYYMMDD`를 연 뒤 같은 출처에서 날짜별로 fetch해 팀별 경기 수를 센다(약칭 GS→GSW, WSH→WAS, NY→NYK, SA→SAS, UTAH→UTA, NO→NOP). landofbasketball.com은 작업 공간 허용 목록에서 막히고, cdn.nba.com은 접근 거부였다.
