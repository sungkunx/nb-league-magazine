# 발행 계획

무엇을 언제 쓰는지 정리한 문서다. 글 파일의 형식은 `docs/publishing.md`.

## 정해진 글

| 글 | `kind` | 언제 | 횟수 |
|---|---|---|---|
| 드래프트 평가 | `draft` | 드래프트 다음 날 | 시즌 1회 |
| 개막 전 영입 평가 | `preseason` | 드래프트~개막 전날의 트랜잭션, 개막 직전 | 시즌 1회 |
| 주간 시작 | `week-start` | 주 초, 대진 미리보기 | 매주 |
| 주간 중간 | `week-mid` | 주중 점검 | 매주 |
| 주간 마지막 | `week-end` | 주가 끝난 뒤 결산 | 매주 |
| 만평 | `week-cartoon` | 주가 끝난 뒤, 결산과 함께 (시점은 바뀔 수 있음) | 매주 |
| 플레이오프 특집 | `playoff` | 20주차 시작 전, 전 팀 분석 | 시즌 1회 |

## 드래프트 전 특집 (운영자가 따로 요청한 글)

- `draft-avoid.md`(시즌 초에 피할 선수), `draft-sleepers.md`(후순위 가성비 후보). `kind: preseason`.
- 팩트시트가 없는 시점의 글이라 바깥 보도를 근거로 쓴다. 이때는 글 머리에 기준일을 적고,
  주장마다 직접 열어 확인한 출처를 글 끝에 단다. 기억으로 쓰지 않는다.
- 사생활·징계는 주요 매체가 사실로 보도한 것만 쓴다. 소문은 싣지 않는다.

## 만평

- 주간 글과 따로 나가는 별도의 글이다. 주간 시작/중간/마지막 글에는 만평을 넣지 않는다.
- 한 주에 한 편, 그림 3장. 그림마다 바로 아래에 재미있는 코멘트 한 줄.
- 그림은 운영자가 ChatGPT로 직접 만든다. 쓰는 쪽은 그림 3장의 **프롬프트 문안**과
  **코멘트 3줄**을 운영자에게 보내고, 그림 파일을 받으면 글을 만든다.
- 소재는 그 주 팩트시트에 있는 일만 쓴다. 코멘트에 숫자를 쓰면 팩트시트의 숫자여야 한다.
- 선수 개인을 놀리는 소재는 CLAUDE.md의 기사 작성 규칙(개인 기록이 뒷받침할 때만)을 따른다.

## 호외

- 정해진 일정 밖의 특집 기사다(`kind: extra`).
- 쓸지 말지는 **매일 경기가 끝난 뒤의 수집(오후 수집)이 끝난 다음** 정한다.
  그날 새로 들어온 데이터에서 평소와 다른 일이 보일 때만 쓴다. 없으면 쓰지 않는다.
- 근거는 수집된 데이터에 있어야 한다. 바깥 뉴스나 기억으로 쓰지 않는다.
- 하루에 많아야 한 편. 그날 나가는 정규 글이 같은 일을 다루면 호외로 따로 쓰지 않는다.
- 다른 글과 마찬가지로 운영자 확인을 거친다(`config/site.json`의 `auto_publish`).

무엇이 "평소와 다른 일"인지의 기준은 시즌을 돌려 보며 다듬는다. 출발점:

- 트레이드 성사, 또는 하루에 여러 팀이 얽힌 큰 이동
- 한 팀이 하루에 낸 기록이 시즌 들어 리그 최고/최저인 경우
- 벤치(BN)에 둔 선수의 기록이 그날 선발 누구보다 좋았던 경우
- 야간 라인업과 실제로 쓴 라인업이 달라서 매치업 카테고리의 승패가 갈린 경우
- 주 초반에 영입 4회를 다 쓴 팀, 시즌 영입 한도에 가까워진 팀
- 주중에 이미 뒤집기 어려운 차이가 났거나, 반대로 하루 만에 뒤집힌 매치업
